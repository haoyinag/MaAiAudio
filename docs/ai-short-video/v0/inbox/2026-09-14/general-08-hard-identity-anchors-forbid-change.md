# 硬身份锚点 3–5 个写「不得改变」；定妆照正脸中性均匀光

- 维度：通用技巧
- 日期：2026-09-14

## 一句话

选 3–5 个硬身份锚点，少而硬；定妆照正脸、中性表情、干净背景、均匀光；禁改项写「不得改变」，勿写「尽量保持」。

## 要点

- 相对 09-12「7-panel 资产圣经」与 09-13「角色参考预审」：那边记结构表与审核门；本条只记锚点怎么选、定妆照怎么拍、禁改怎么写，不重开 7-panel 或预审流程。
- 选 **3–5 个硬身份锚点**（脸型 / 发型轮廓 / 眼色 / 外套剪裁 / 耳饰等），少而硬，勿堆形容词。
- 定妆照：正脸、中性表情、干净背景、均匀光——勿用戏剧斜脸强光。
- 禁改项写 **「不得改变」**，勿写「尽量保持」。
- 审片先看一致性再看美感。
- 主角 / 高频配角要三视图；路人可简化，但不能与主角共用宽泛描述。

## 可执行

- 角色卡只留 3–5 个可辨锚点（例：圆脸、齐刘海轮廓、棕色瞳、短款皮衣剪裁、左耳圆环）；删掉「英俊 / 气质冷」一类软词。
- 定妆照按「正脸 + 中性表情 + 干净背景 + 均匀光」收；戏剧斜脸、伦勃朗光不当主参考。
- 提示词与分镜的禁改句一律写成「不得改变发型轮廓 / 不得改变外套剪裁」，禁止「尽量保持」。
- 审片顺序：先过锚点一致性，再评构图与光；锚点漂了直接拒，不靠调色补救。
- 主角与高频配角补三视图；路人描述不得复用主角的宽泛外貌句。
