# general 精选｜高频动作先降维成可验收状态

## 当前最优解法 (Do)

- 对万相 3.0，把“一秒完成 N 次”改写为“起始姿态 → 一次明确动作 → 结束姿态”，每段只留一个主要动作目标。
- 必须保留精确次数时拆镜，或先慢动作生成再后期变速；分镜表同时记录时间段、动作终态与验收点。
- 来源：阿里云百炼当前 Prompt 指南；provenance 见 [原子稿](../../../inbox/2026-11-20/general-wan3-high-frequency-motion-boundary.md)。

## 已知困境与避坑边界 (Don't / Bottlenecks)

- 不把时间戳当作运动解析能力；官方明确将“一秒摇头 3 次”列为难控示例。
- 不把当前万相建议外推成所有模型的统一镜长或成功率；官方未公布废片率，拆镜也不是成功保证。
