# 增长变现：YouTube 2027 分开计算入驻、活跃与 Shorts 月度收益门槛

- **主维度：** `growth`（增长变现）
- **来源 URL：** https://support.google.com/youtube/answer/12843009?hl=en
- **发布机构 / 作者：** YouTube Help
- **发布日期：** 页面未标明；规则标注自 2027-02-01 起生效
- **采集日期：** 2026-11-16（Asia/Shanghai）
- **来源等级：** 平台官方帮助文档
- **核验状态：** `已核验`
- **适用平台 / 地区：** YouTube Partner Program 可用地区
- **时效：** 极高；未来生效规则，执行前还应核对 YouTube Studio 的账号通知

## 来源明确事实

1. 自 2027-02-01 起，新创作者进入 YPP 广告与 Premium 收益层的门槛调整为 1,000 订阅者并满足过去 365 天 8,000 个合格观看小时，或过去 90 天 2,000 万个合格 Shorts 观看。
2. 已在 YPP 的频道按另一套活跃口径判断：过去 365 天 1,000 个合格观看小时、过去 90 天 100 万个合格 Shorts 观看，或每 90 天发布 2 条长视频 / 5 条 Shorts，满足其一即可。
3. Shorts Creator Pool 的月度收益另有最低表现条件：过去 90 天保持 1,000 万个合格 Shorts 观看；未达到不会移出 YPP，也不影响长视频等其他 YPP 收益。
4. 广告主若把 Shorts 广告定向到不超过 5 个频道的组，符合资格的创作者可获得该定向投放净收益的 45%，并叠加在普通 Creator Pool 收益之外。

## 分析推断

- “加入 YPP”“保持频道活跃”“当月获得 Shorts Creator Pool 分成”是三套不同门槛，不能共用一个达标状态。
- 定向 Shorts 广告是独立收入项，不应并入普通 Shorts 池估算 RPM。

## 可执行含义

1. 运营看板拆成 `YPP 入驻资格 / YPP 活跃状态 / Shorts 月度池资格 / 定向广告收入` 四栏，并保留各自滚动窗口。
2. 对已入驻频道，不用新创作者的 2,000 万 Shorts 门槛误判频道会被移出；先核对活跃口径和 90 天补救窗口。
3. 在 2027-01-31 前逐频道核验并接受适用的 Watch Page、Shorts 与 Commerce 模块条款。
