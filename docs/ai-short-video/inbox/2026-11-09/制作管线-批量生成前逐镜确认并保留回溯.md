# 制作管线：批量生成前逐镜确认，并保留候选与提示词回溯

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://docs.volcengine.com/docs/drama-creation/short-play-creation?lang=zh

- **发布日期：** 页面最近更新于 2026-08-10
- **采集日期：** 2026-11-09（Asia/Shanghai）
- **来源等级：** 模型厂商官方产品文档
- **核验状态：** `已核验`
- **适用平台 / 地区：** 火山剧创；中国大陆，流程可映射到其他分镜式生产工具
- **时效：** 高；产品功能与模型限制会变化

## 来源明确事实

1. 官方流程按剧本解析、资产设定、分镜生成和视频预览组织，并建议查看、确认全部分镜后再批量生成视频。
2. 角色、场景、道具和音色可以在提示词中精确关联；老项目需要手动升级提示词编辑器以更新素材关联。
3. 单个分镜可生成多个候选，用户可指定当前采用的片段，并回溯该候选生成时的提示词。
4. 完整预览后可下载选中片段或导出剪映草稿继续编辑；文档没有承诺批量生成等于自动通过质量验收。

## 分析推断

- 批量按钮应位于“分镜与资产绑定已冻结”的门后；否则脚本或角色资产的早期错误会被成倍放大。
- 候选片段必须和生成提示词一起留档，否则选片后无法稳定复现或定位差异。

## 可执行含义

1. 批量生成前设置四项闸门：分镜顺序、角色 / 场景 / 道具绑定、台词时长、目标模型。
2. 每镜记录 `候选 ID / 提示词 / 模型 / 选择理由 / 返修原因`，不要只保存最终 mp4。
3. 老项目升级编辑器后先抽查 2–3 镜的素材关联，再批量重跑；导出前做全剧预览。
