# 制作管线：万相参考视频按输入与成功输出总秒数算账

- **主维度：** `pipeline`
- **来源 URL：** https://help.aliyun.com/en/model-studio/model-pricing
- **辅助来源：** https://help.aliyun.com/en/model-studio/text-to-video-guide
- **发布机构 / 作者：** Alibaba Cloud Model Studio
- **发布日期：** 页面未标明
- **采集日期：** 2026-11-20（Asia/Shanghai）
- **来源等级：** 模型厂商官方计费文档
- **核验状态：** `交叉验证`
- **适用平台 / 地区：** 阿里云百炼万相视频模型；具体区域与模型以控制台为准
- **时效：** 极高；价格、折扣、免费额度和区域均可能变化

## 来源明确事实

1. 官方价格页说明，部分万相参考视频任务的计费时长为输入视频时长与成功输出视频时长之和；不能只按成片秒数估算。
2. 页面列出的 Wan 3.0 免费额度仅在中国（北京）区域提供，并自激活、模型发布或申请批准三者中较晚日期起 90 天有效。
3. 文生视频官方指南说明输入免费、仅按成功输出秒数计费，失败调用或处理错误不收费也不消耗免费额度；不同任务类型的计费公式因此不能混用。

## 分析推断

- “每秒单价”必须与任务类型、输入秒数、输出秒数、区域和额度有效期一起记录。把文生视频公式套到参考视频任务会系统性低估成本。

## 可执行含义

1. 成本台账增加 `task_type / region / input_seconds / successful_output_seconds / quota_expiry / list_price_or_discount` 字段。
2. 参考视频进入生成前先裁掉无用片头片尾；但必须保留完成任务所需的动作与时序信息，不能为省输入秒数破坏控制信号。
3. 免费额度到期前设置提醒；预算评审按无免费额度的常态价格复算，避免把试用期成本当长期 ROI。

## 已知困境与边界

- 本条没有固化页面上的具体单价，避免把易变价格写成长期事实；执行时应重新打开官方价格页。
- “失败不收费”不等于“成功但不可用可退款”；官方没有为审美不合格或提示漂移承诺退款。
- 与既有 Seedance / Runway 成本原子互补，不可跨厂商类推退款规则。
