# 生图首尾固定角色特征，口型差改侧面/远景

- 维度：通用技巧
- 日期：2026-09-13

## 一句话

生图提示词用「首尾固定法」锁五官服装；口型对不上就改侧面或远景兜底，不要死磕正脸口型。

## 要点

- 相对 09-12「即梦权重 0.7–0.8 + 运动三要素」（同文已顺带写过首尾重复）：本条只抽出生图提示结构与口型兜底，不重开权重、I2V 时长或剪映导出。
- 首尾固定法：提示词开头写关键角色特征，结尾再重复一遍五官/发型/服装；中间只写场景与动作，避免中段改写人设。
- 口型同步对一致性要求更高；效果不好时用侧面镜或远景镜回避，观众对远景口型更不敏感（来源作者经验，待核）。
- 本条是生图/口型兜底，不是即梦入口分流（上午「首尾帧 vs 全能参考」）。

## 可执行

- 生图提示固定三段：开头角色特征 → 中间场景动作 → 结尾再写一遍五官与服装关键点。
- 中段禁止改发型、换装、改脸型；服装变化只写在剧本已标注的换装镜。
- 口型镜先正脸试；口型漂或脸僵，改侧面或远景重渲，禁止同一正脸设置盲抽。
- 远景/侧面兜底镜仍复用同一套首尾特征句，避免人设漂移。
