# Seedance 2.0 多模态上限与 @素材名分工

- 维度：制作管线
- 日期：2026-09-14

## 一句话

按手册口径（待核）：图≤9、视频≤3 且总时长≤15s、音频≤3 且总时长≤15s；生成时长可选约 4–15s。用 `@素材名` 分工，并分清首尾帧入口与全能参考入口。

## 要点

- 相对 09-13「即梦首尾帧 vs 全能参考 + @素材名」：那边只记入口分流；本条补数量/时长上限与模态分工，不重开入口按钮说明。
- 作者手册口径（待核，上线前以当前 UI 为准）：图片输入 ≤9 张；视频输入 ≤3 个且总时长不超过约 15s；音频输入 ≤3 个且总时长不超过约 15s；生成时长可在约 4–15s 自选。
- 交叉来源另记混合输入总文件约 ≤12（第三方指南，待核）；与分项上限并存，勿把 9+3+3 当成必须用满。
- `@素材名` 分工：图锁人/风格，视频锁动作与运镜，音频锁节奏与口型。不标注用途时模型会猜，参考可能被当成背景。
- 仅首帧图+prompt → 首尾帧入口；图/视频/音频/文本组合 → 全能参考入口。智能多帧 / 主体参考不可选时以手册为准。

## 可执行

- 开渲前先填参考配额：图几张、视频几段（合计秒数）、音频几条（合计秒数）；任一项超手册上限先裁，不要赌 UI 放行。
- 提示词里每条素材写清用途，例：`@图片1` 锁角色，`@图片2` 锁场景风格，`@视频1` 锁动作/运镜，`@音频1` 锁节奏或口型。
- 只有一张首帧图：走首尾帧。有视频或音频或超过一张图：走全能参考。
- 参考视频/音频优先短而准；不要为「用满 15s」拼接无关素材。混合文件数先按影响最大的几条排，不追求用满 12。
