# 渲前四道评审门：角色/分镜/声线/预算

标签: 评审门,管线

## 要点
- 角色门：多角度可认、情绪可用、角色互不撞脸，过门再视频
- 分镜门：一镜一职；塞三拍+道具揭晓+动作+环绕则拆镜
- 声线门：每句有说话人/情绪/节奏/落点；有的台词放反应镜；视觉已说清则删句
- 预算门：全镜便宜档草稿 → 选 keeper → 升档精修
- 短场常见 3–6 镜：钩子/插入/反应/动作/揭晓/转场
