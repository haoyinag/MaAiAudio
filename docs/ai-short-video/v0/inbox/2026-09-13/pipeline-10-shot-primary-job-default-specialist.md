# 每镜一个 primary job，默认模型扛常规、专长模型补失败

- 维度：制作管线
- 日期：2026-09-13

## 一句话

先写死本镜「必须保住」的一件事，再选型；默认模型扛常规镜，专长模型只在默认反复失败或刚需能力时启用。

## 要点

- 相对上午「按最难点选型 / 八层提示词」与 09-12「戏型分模 / 分模矩阵」：本条只记 job 配额与默认+专长启用门槛，不重开 Veo/Kling/Seedance 戏型表或能力矩阵。
- 每镜一个 primary job，最多两个 secondary。先定必须保住的那一项（身份 / 产品几何 / 动作 / 对白 / 声音 / 末帧），再选最可能护住它的路由。
- 对白特写常见 primary=脸与口型时机；追逐镜常见 primary=解剖与动量；产品微距常见 primary=边缘与标签形状；建立镜常见 primary=构图与氛围（来源工作流归纳，待核）。
- 指定一台默认模型扛常规镜，避免全片变成「每镜换引擎」的运维题。专长模型只在默认路线反复失败，或某项能力本镜刚需（如原生对白、动作物理、参考保真）时启用。
- 多模型工作流是「同一 brief / 参考 / 调色规则，只换渲染引擎」，不是另开一条制作。

## 可执行

- 分镜表加三列：primary job、secondary（≤2）、必须保住项；未填不选型、不开渲。
- 先指定默认模型跑常规镜；日志里连续失败或刚需能力缺位，才切专长路由。
- 选型只问「谁更可能保住 primary」，禁止按排行榜或「更好看」换模。
- 换引擎时冻结剧本、参考包、画幅与交付设置；只改渲染端。
