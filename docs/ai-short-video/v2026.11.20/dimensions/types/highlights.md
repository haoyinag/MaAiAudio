# types 精选｜微短剧先通过项目级类型验收

## 当前最优解法 (Do)

- 立项卡写清主题主线、角色目标、每集因果链与季级闭环；再把逐镜生成指标挂在项目目标之下。
- 送审粗剪同时检查画面、声音、字幕与时码；上线排期以适用的许可、批准文件或节目编号为硬门禁。
- 来源：国家广播电视总局现行《微短剧发展管理办法》；provenance 见 [原子稿](../../../inbox/2026-11-19/types-microdrama-project-acceptance-boundary.md)。

## 已知困境与避坑边界 (Don't / Bottlenecks)

- 不把“竖屏 + 短时长”当作微短剧成立条件，也不用无声样片代替完整送审版本。
- 法规定义不是流量公式或扶持保证；分类仍取决于投资额度、题材及主管部门当前口径。
