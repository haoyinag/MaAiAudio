# 合规与风控：AI 侵权处置要延伸到停止生成与屏蔽相关指令

- **主维度：** `compliance`（合规与风控）
- **来源 URL：** https://www.court.gov.cn/zixun/xiangqing/511101.html
- **补充来源 URL：** https://ipc.court.gov.cn/zh-cn/news/view-6032.html
- **发布机构 / 作者：** 最高人民法院；最高人民法院知识产权法庭
- **发布日期：** 2026-09-07
- **采集日期：** 2026-11-15（Asia/Shanghai）
- **来源等级：** 最高人民法院司法意见及官方答记者问
- **核验状态：** `已核验`
- **适用平台 / 地区：** 中国大陆；生成式 AI 视频、数字人、换脸拟声工具及使用这些工具的短视频制作团队
- **时效：** 高；依据法发〔2026〕10 号，平台和服务商的具体通知入口、处置流程仍可能变化

## 来源明确事实

1. 生成式人工智能自动生成的内容侵害他人名誉权、隐私权等人格权益时，权利人通知应包含构成侵权的初步证据及权利人的真实身份信息。
2. 服务提供者收到通知后未及时采取停止生成侵权内容等必要措施的，应当依法对造成的损害承担侵权责任。
3. 网络用户通过输入侵权提示词等方式恶意诱导生成侵权内容并造成他人损害的，该用户应当依法承担侵权责任；服务提供者收到权利人通知后仍未及时停止生成、屏蔽相关生成指令的，法院依法支持权利人依据民法典第一千一百九十五条主张责任。
4. 对正在实施或即将实施、且不及时制止会造成难以弥补损害的人格权侵害，法院可以依法责令网络用户停止行为，或责令网络服务、生成式人工智能服务提供者停止提供有关服务；措施不得超出必要限度。

## 分析推断

- 成片下架不是唯一处置点：同一侵权人物、声音或不实情节仍可被相同指令重复生成时，风险尚未闭环。
- 短视频团队既是生成工具用户，也可能是权利受损方；因此需要同时保留“生成记录”和“通知处置记录”，但不能把一切相似提示词都推定为恶意。

## 可执行含义

1. 生成记录至少关联输入素材、提示词、模型与版本、生成时间、操作者和发布版本；高风险人物 / 声音另存授权依据。
2. 收到权利通知时先核对真实身份、初步侵权证据和具体输出，再按成片下架、停止继续生成、屏蔽相关指令或人工复核分级处置，并记录时间线。
3. 自身被仿冒时，通知材料明确给出可识别人物 / 声音、侵权输出链接或样本、生成服务线索和初步权利证明；如损害正在快速扩大，再评估人格权侵害禁令等法定救济。
4. 屏蔽规则应限定到已核验的侵权对象和生成模式，保留申诉与复核，避免把正常讽刺、虚构或已授权内容一并误伤。
