# 制作管线：Runway Agent 先审生成计划，再花积分制作与组装

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://help.runwayml.com/hc/en-us/articles/51601639579667-Creating-with-Runway-Agent
- **发布机构 / 作者：** Runway Help Center
- **发布日期：** 页面未标明
- **采集日期：** 2026-10-22（Asia/Shanghai）
- **来源等级：** 模型厂商官方文档
- **核验状态：** `已核验`
- **适用平台 / 地区：** Runway；海外，方法可迁移至按积分计费的生成工具
- **时效：** 产品功能易变，核验至 2026-10-22

## 来源明确事实

1. Runway Agent 可规划并生成图像、视频、音频、音乐和配音，制作参考表、分镜、脚本与多镜头时间线，并在内置编辑器中剪切、重排和补充素材。
2. “生成前询问”模式会展示每一步的模型、提示词和预计积分成本并等待确认；自动模式则在规划后立即生成。
3. 用户可以让模型选择优化速度、成本或质量，也可自定义模型、分辨率和画幅偏好。
4. 官方明确说明计划只代表意图、不保证结果，并建议生成前审阅故事节拍、视觉和配音；较长视频会拆成受模型时长限制的多个片段再组装。

## 分析推断

- Agent 化工作流最有价值的控制点是“计划—审批—生成”闸门，而不是把全部环节改为自动；这能在消耗积分前发现叙事、画幅和模型路由错误。
- 代理自动选模不能替代验收，尤其是跨模型片段的一致性、音画同步和授权检查。

## 可执行含义

1. 默认开启生成前确认，审批模型、提示词、画幅、预计积分和镜头清单。
2. 先用 720p 或低成本档迭代镜头结构，成片确认后再升级分辨率；实际成本仍以账户页面为准。
3. 对自动拼接的多镜头成片逐段检查身份、道具、色调、声音和转场，不把“已组装”当作“已验收”。
