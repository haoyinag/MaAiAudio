# Kling Native Audio 口型清单：姓名+台词紧挨，复杂句拆短

- 维度：制作管线
- 日期：2026-09-14

## 一句话

Native Audio 口型：说话人脸可读；姓名与台词紧挨；复杂句拆短；多角色用 `Name (tone): line`；交付注记仅在有用时加。

## 要点

- 相对 09-13「口型差改侧面/远景」兜底：那边记失败后改景别；本条只记写进 prompt 的口型清单，不重开口型侧远改法。
- 说话人脸须可读，景别别太远（正脸或近中景优先）。
- 说话人姓名 + 台词紧挨写，不要把名字和句子拆到提示词两端。
- 交付注记（whisper / surprise / low voice 等）只在对表演有用时加，勿每句堆情绪标签。
- 复杂句拆成短句；可写环境声（如空调轻嗡），给口型一条稳定底噪。
- 多角色用 `Name (tone): line` 指代，避免「他说/她说」指代漂移。
- 支持中 / 英 / 日 / 韩 / 西，以及方言口音标签（粤语、四川话、Indian accent 等，以产品为准）。

## 可执行

- 对白镜先确认说话人脸在画内可读，再写口型提示；远景对白先改景别，不先加长台词。
- 提示词写成「姓名 + 紧挨的台词」；多角色统一 `Name (tone): line`，一角色一行。
- 超过一个从句的句子先拆短；whisper / surprise / low voice 只标真正需要的那一句。
- 需要空间感时加一条轻环境声（如空调轻嗡），不要用大声音乐盖过口型。
- 口音标签按产品已支持项勾选（粤语 / 四川话 / Indian accent 等），未列出的方言先测一条再批量。
