# AI 短视频 / 短剧知识库

持续收集 **AI 短视频**、**AI 短剧** 的制作与增长经验，形成可检索、可迭代、可溯源的内部知识库。

本目录是知识库的权威文档树。仓库 Wiki 首页应链到本路径（见 [WIKI.md](./WIKI.md)）。

## 怎么读

1. 打开 [CURRENT.md](./CURRENT.md) 看最新可读
2. 读最新 DIGEST / CHANGELOG（日摘要 / 版摘要）
3. 需要细节再下钻原子稿；INDEX 与 `dimensions/*` 仅溯源

## 版本节奏

- **每日巡扫**：把新线索写成 inbox / 草稿，先入库、后定稿。
- **约每 3 天发一版**：将已核验条目并入 `vN/`，并更新 [CURRENT.md](./CURRENT.md) 指向最新版本。
- 旧版本目录保留，便于对照与回滚阅读，不原地改写已发布条目的事实结论。

## 来源与写作约束

- **必须标注来源**：每条经验写明原始链接与观察/采集日期。
- **去重**：同一事实或同一案例不重复落条；重复线索在 inbox 中合并并保留更完整的出处。
- **不编造**：没有出处的数字、案例、平台规则不要写入正式条目；不确定的内容停在 inbox，并标明「待核验」。
- **不写入密钥或本机绝对路径**：正文只用仓库相对路径与公开链接。
