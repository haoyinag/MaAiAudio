## 今日结论

1. 生成控制要按精度路由：宫格负责叙事和构图，多关键帧负责严格状态；批量生成前先冻结分镜与资产绑定，并保留候选、提示词和选择理由。
2. 平台标识与内容许可分开：TikTok 的 AI 标签本身不等于限流，但禁止内容不会因标注放行；YouTube 的人物肖像主张也不会因 AI 披露而消失。
3. 微短剧运营不只看首发：首集需要按长尾发现维护本地化和承接；品牌连载要先决定进入创作者世界，还是让品牌承担系列主线。
4. 自动剪辑与投流工具证明的是供给能力，不是效果。对白 / 纯视觉先分流，素材生成、过审、消耗、转化和回收分别记账。
5. 易变边界必须立即处理：Sora Web / App / API 已停用，应尽快导出；国内当前专项治理覆盖正片之外的标题、宣推、引流、换名重播和公众人物仿冒。
