# 平台技巧：快手小说剧收到视频 ID 后先确认转码再提审

- **来源 URL：** https://open.kuaishou.com/docs/operate/specification/integrationGuide/apiGuide.html
- **发布机构 / 作者：** 快手开放平台
- **发布日期：** 2026-09-14（页面标注更新时间）
- **采集日期：** 2026-11-26（Asia/Shanghai）
- **来源等级：** 平台官方接入文档，第 2.2 节、视频错误码及 FAQ
- **核验状态：** `已核验`
- **适用平台 / 地区：** 快手小说剧开放平台获授权接入方，中国大陆
- **时效：** 高；生产接入前复核权限与格式要求

## 来源明确事实

小说剧 URL 上传仅支持 MP4。快手建议有时效的源链接保留足够长的下载窗口，避免排队时资源过期；文档建议一周。返回的 `videoId` 可用于查询状态，状态区分处理中、转码成功、转码失败、视频拉取失败。官方提醒回调可能重复或遗漏，建议用查询接口核对状态。FAQ 举例说明即使拿到 ID，源视频为空、黑屏或资源没有上传成功仍可能无法使用。

## 分析推断

制片交付可单列「文件可播、平台转码成功、内容审核通过」三个状态，避免把技术故障算进剧集内容拒审率。

## 可执行含义

1. 上传前用本地播放器确认 MP4 可播、有画面、有内容，检查片尾和时长。使用有效期足够的源链接。
2. 按集保存 `videoId`。对重复回调做幂等处理，并对回调遗漏补查状态；转码成功后再发起关联或提审。
3. 若报空视频、黑屏或拉取失败，先查源文件和链接，再按平台指引重新上传取得新 ID。内容审核的问题按剧、集分别查。

## 已知困境与边界

有资源 ID 只说明可用该 ID 查询记录。平台的 URL 上传格式限制和回调行为适用于小说剧接入，常规 App 投稿适用各自的规则。接入文档写明权限需联系运营人工添加，无法据此认定所有账号可以调用。
