# inbox — 扫描草稿暂存

每日巡扫到的线索先写在本目录，**不定稿、不直接当作正式条目**。

inbox 的默认阅读入口是各日目录下的 `DIGEST.md`（日摘要），**不是逐个原子稿**。INDEX 与 `dimensions/*` 只作溯源：需要细节参数时再下钻。

## 用法

1. 一条线索一个草稿文件，或按日期合并成当日草稿。
2. 每条至少包含：现象 / 做法、来源链接、观察或采集日期。
3. 信息不足或相互矛盾时标明「待核验」，不要补写未见到的细节。
4. 与已有草稿或正式条目重复时合并出处，不另开一条。
5. 约每 3 天发版时，只把已核验内容迁入对应 `dimensions/`，并在草稿中注明去向。

## 建议文件名

- 按日：`YYYY-MM-DD.md`
- 按主题：`YYYY-MM-DD-<短标题>.md`

不要在草稿正文中写入密钥或本机绝对路径。
