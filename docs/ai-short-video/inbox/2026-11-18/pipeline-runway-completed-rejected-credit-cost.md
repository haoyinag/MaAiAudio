# 制作管线：Runway 成片不满意仍消耗积分

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://help.runwayml.com/hc/en-us/articles/34266159290003-Can-I-have-credits-refunded
- **辅助来源 URL：** https://help.runwayml.com/hc/en-us/articles/56617505841939-Why-doesn-t-my-generation-match-my-prompt
- **发布机构 / 作者：** Runway Help Center
- **发布日期：** 页面未标明
- **采集日期：** 2026-11-18（Asia/Shanghai）
- **来源等级：** 模型厂商官方帮助中心
- **核验状态：** `交叉验证`
- **适用平台 / 地区：** Runway；其服务开放地区
- **时效：** 高；积分、模型和代理设置可能变化

## 来源明确事实

1. Runway 只为以 generation error 结束的任务自动返还积分；任务成功完成后，即使不符合提示、未保持相似度或成片不可用，也不会自动返还积分。
2. 官方建议在 Agent 中启用 `Ask before generating media`，先展示计划、模型和估算积分，再由用户批准生成。
3. 官方建议调试阶段使用较低分辨率，保留最终版本后再放大；不同模型每秒积分成本不同。

## 分析推断

- “技术完成率”与“可交付成片率”必须分开记账；只统计报错任务会低估废片成本。
- 代理自动执行若没有生成前审批门，会把错误路由或过度迭代直接转化为不可退款积分。

## 可执行含义

1. 项目账本分别记录 `errored / completed-rejected / completed-approved`，以 `completed-rejected` 计算真实废片成本。
2. Agent 默认启用生成前确认；审批卡显示模型、时长、分辨率、预计积分和本轮变更项。
3. 先用低分辨率做单变量迭代，只对通过内容验收的版本放大；为每镜设置最大尝试次数和积分上限。

## 已知困境与边界

- 官方没有给出不同题材或模型的平均废片率，不能据此估算统一 ROI。
- 规则只适用于 Runway 当前平台，不外推到第三方聚合平台或其他模型厂商。

## 与既有条目的关系

- **增量：** 新增“成片不满意仍扣费、只有错误任务自动返还”的明确成本边界和三态记账法。
