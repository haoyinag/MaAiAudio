# 通用技巧：按输入模态拆分视频提示词，不把图生视频重复写成文生视频

- **主维度：** `general`（通用技巧）
- **来源 URL：** https://help.aliyun.com/zh/model-studio/text-to-video-prompt
- **发布机构 / 作者：** 阿里云百炼 Model Studio
- **发布日期：** 2026-10-10（页面更新时间）
- **采集日期：** 2026-10-22（Asia/Shanghai）
- **来源等级：** 模型厂商官方文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** 万相；方法可作为其他视频模型的测试假设；中国大陆 / 全球
- **时效：** 当前产品文档，模型能力与字段可能变化

## 来源明确事实

1. 文生视频的进阶公式为“主体 + 场景 + 运动 + 美学控制 + 风格化”；美学控制包含光源、景别、视角、镜头和运镜。
2. 图生视频因输入图像已经确定主体、场景和风格，官方建议提示词主要描述运动过程与运镜，公式简化为“运动 + 运镜”。
3. 对支持原生音频的万相版本，官方把声音拆为人声、音效和背景音乐；人声还可描述台词、情绪、语调、语速、音色和口音。

## 分析推断

- 提示词模板应随输入模态切换。把主体和风格在图生视频中反复重写，可能增加冲突，但来源没有给出量化失败率，需用同一素材 A/B 验证。
- 音画同生时可把声音当作分镜字段，而不是生成后才补的附注；是否优于独立配音仍取决于项目的可编辑性要求。

## 可执行含义

1. 文生视频镜头表保留主体、场景、运动、美学、风格五栏；图生视频镜头表默认只保留运动、运镜及必要约束。
2. 音画同生模型另设人声、音效、背景音乐三栏，并逐镜检查声画同步。
3. 每次只修改一个字段，记录可接受镜头率，避免把厂商公式直接当作跨模型定律。
