# 增长变现：快手星火任务按归因与审核后收益分账

- **主维度：** `growth`（增长变现）
- **来源 URL：** https://open.kuaishou.com/docs/operate/reviewSpecification/sparkProject/sparkProject.html
- **发布机构 / 作者：** 快手小程序 / 达人开放平台
- **发布日期：** 页面最近更新于 2025-10-31
- **采集日期：** 2026-11-13（Asia/Shanghai）
- **来源等级：** 平台官方运营文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** 快手星火计划小程序任务；中国大陆
- **时效：** 极高；资格、比例、费用、结算日和审核可变

## 来源明确事实

1. 快手达人开放平台将小程序任务分为广告分成、收入分成和线索转化三类，分别对应小程序内广告曝光、付费订单与有效线索。
2. 归因起点是用户从创作者短视频挂载入口进入小程序；后续收益再按任务类型计算，不是单纯按视频播放量结算。
3. 当前文档说明达人任务采取“先发作品、收益下发前审核”；不符合任务要求或存在作弊、刷单的作品可不予结算。
4. 页面同时列出达人信息服务费、退款、预算冻结与下发周期等细则；页内对部分充值阈值存在“大于 27%”与“大于 28%”的表述不一致，本条不把该阈值作为执行结论。

## 分析推断

- 这类任务的业务账本至少需分开“视频流量”“挂载点击”“小程序行为”“审核通过”和“实际到账”，否则会把曝光误当收入。
- AI 批量出稿只降低素材制作成本，不改变任务审核、有效转化和反作弊对结算的影响。

## 可执行含义

1. 每个任务记录任务类型、归因口径、审核状态、退款 / 无效线索、费用和到账日，按净到账计算回报。
2. 发布前把必选要求、授权素材、明星 / 达人背书和挂载落地页做成验收表；发布成功不标记为“收益确认”。
3. 实际投放前在达人开放平台内再核验当前比例、费用和结算条款；对页内冲突阈值向平台客服确认。

## 与既有条目的关系

- **增量：** 既有快手条目聚焦 AIGC 扶持与常态收益分账；本条增加小程序任务的三类归因、收益前审核与净到账账本。
