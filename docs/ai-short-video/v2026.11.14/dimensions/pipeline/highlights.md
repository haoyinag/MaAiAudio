# 制作管线 · 本维精选

## 批量按钮放在分镜与资产冻结之后

### 来源事实

火山剧创官方流程按剧本解析、资产设定、分镜生成与视频预览组织，并建议确认全部分镜后再批量生成。单镜可保留多个候选、指定采用片段并回溯生成提示词；完整预览后再下载片段或导出后续编辑。

### 分析与行动

- 批量生成前检查分镜顺序、角色/场景/道具绑定、台词时长和目标模型。
- 每镜保存 `候选 ID / 提示词 / 模型 / 选择理由 / 返修原因`。
- 编辑器或素材关联升级后先抽查少量镜头，再批量重跑；导出前完成全剧预览。

### 边界与溯源

厂商文档没有承诺批量生成等于质量验收通过。原子稿与来源：[批量生成前逐镜确认并保留回溯](../../../inbox/2026-11-09/制作管线-批量生成前逐镜确认并保留回溯.md)。
