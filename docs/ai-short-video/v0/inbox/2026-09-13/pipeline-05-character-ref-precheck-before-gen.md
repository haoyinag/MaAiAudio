# 角色参考预审再进视频生成

- 维度：制作管线
- 日期：2026-09-13

## 一句话

写实真人角色的瓶颈常在资产审核与上下文切换：参考图先过资产库审核，再进视频生成。

## 要点

- 写实真人角色易撞内容审核；实务是先把角色参考图导入资产库完成审核，再用于视频生成。
- 跳过预审时，「真人视频」类调用常无明确原因失败，容易被误判成模型或提示词问题。
- 瓶颈常在资产工作流与上下文切换（脚本/角色/场景/渲染拆在多个工具），不在再装一个生成器。
- 成片用多段稳定短镜拼接；作者称生成约一半、剪辑约一半（作者经验，待核）。
- 相对 09-11「锁表再渲」：本条盯审核门，不重开定妆表字段。

## 可执行

- 写实角色参考图先入库并等审核通过，再挂到视频生成；未过审的图不进「真人视频」调用。
- 无明确原因的真人视频失败，先查参考图审核状态，再改提示词或换模型。
- 把脚本、角色、场景、渲染收敛到同一资产库上下文，减少平台间来回切换。
- 成片按稳定短镜拼接；时间盒按「生成约一半 / 剪辑约一半」排（作者经验，待核）。
