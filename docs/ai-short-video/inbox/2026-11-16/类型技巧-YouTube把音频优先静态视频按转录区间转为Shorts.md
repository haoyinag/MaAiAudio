# 类型技巧：YouTube 把音频优先静态视频按转录区间转为 Shorts

- **主维度：** `types`（类型技巧）
- **来源 URL：** https://support.google.com/youtube/answer/15260303?hl=en-GB
- **发布机构 / 作者：** YouTube Help
- **发布日期：** 页面未标明
- **采集日期：** 2026-11-16（Asia/Shanghai）
- **来源等级：** 平台官方帮助文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** YouTube Studio 桌面端；澳大利亚、加拿大、英国、美国；英文转录的 audio-first 静态视频
- **时效：** 高；实验功能的地区、语言和样式可能变化

## 来源明确事实

1. YouTube Studio 可把通过 RSS 或普通上传进入平台的 audio-first 静态视频转成 8 秒至 3 分钟 Shorts，原视频必须有英文文字转录。
2. 用户可选择系统建议片段，也可在转录文本中逐词指定片段的开始词和结束词。
3. 片段确认后可从四种视觉样式中选择；Short 生成后不能直接更换样式，要换样式必须回到原视频重新开始。
4. 当前功能只在澳大利亚、加拿大、英国和美国的桌面端提供。

## 分析推断

- 这是一条“播客 / 音频优先内容再利用”的独立类型路径：先验收语义完整的转录区间，再验收视觉包装，避免先选样式后被迫迁就不完整片段。
- 官方没有证明建议片段优于人工选段，也没有公开四种样式的稳定性或分发效果。

## 可执行含义

1. 先清理英文转录，再按完整主张、例证或转折选择 8 秒至 3 分钟区间。
2. 把 `转录起止词 / 片段时长 / 视觉样式 / 生成批次` 写入复用账本；样式变更按一次新生成计。
3. 对系统建议片段与人工选段做小批量对照，只比较留存等平台可见指标，不预设自动建议更优。
