# 类型技巧：微短剧按项目级主线与完整情节验收

- **主维度：** `types`
- **来源：** [《微短剧发展管理办法》](https://www.nrta.gov.cn/art/2026/7/31/art_113_73785.html)
- **发布机构：** 国家广播电视总局
- **发布日期：** 2026-07-31（2026-09-01 起施行）
- **采集日期：** 2026-11-19（Asia/Shanghai）
- **来源等级：** 监管部门原文
- **核验状态：** 已核验

## 来源明确事实

办法把微短剧定义为单集少于 20 分钟，且主题主线明确、故事情节连续完整、人物角色突出的剧集。申报审核材料还要求符合要求的图像、声音、字幕、时码样片；未取得相应许可、批准文件或节目编号的内容不得播出。

## 分析推断

“竖屏 + 短时长”不足以构成微短剧。类型开发应把主线、完整情节和突出角色设为项目级验收项，再把镜头生成指标放到其下。

## 可执行含义

1. 立项卡同时写清主题主线、角色目标、每集因果链和季级闭环。
2. 粗剪验收同时检查画面、声音、字幕、时码，不以无声样片代替送审版本。
3. 上线排期以许可 / 批准 / 节目编号为硬门禁。

## 已知困境与边界

- 法规定义不是流量公式，也不保证入选扶持或获得推荐。
- 分类标准还取决于投资额度、题材和后续主管部门口径，项目应核对属地流程。
- 与既有备案和逐集标识条目互补；本条聚焦类型成立与项目验收，不重复标识规则。
