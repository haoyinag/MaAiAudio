# 按通过镜计价，并在开渲前设 retry ceiling

- 维度：制作管线
- 日期：2026-09-13

## 一句话

Cost per approved shot = 该镜总 credits ÷ 通过数；时间账含排队/审片/返工。短低规格先验证，draft 与 final 分路由；连续失败达顶后换路，禁止盲抽。

## 要点

- 相对 09-11「镜数经济学 / 便宜档打样」与 09-12「接受标准批量审」：本条只记通过单价公式、时间全成本与 retry ceiling，不重开按集预算或批量评审清单。
- 生产指标不是「第一条成片有多炫」，而是多少次尝试、多少分钟、多少 credits 才留下一条过审镜。
- 公式（来源作者口径）：Cost per approved shot = 该镜全部尝试所耗 credits ÷ 通过条数。时间同理，须计入上传、排队、渲染、审片、返工、导出。
- 便宜路线若连续拒片，全成本可高于一次通过的高价路线（来源作者归纳，待核）。
- 短时长、低可用分辨率先验证构图与运动；通过后再加对白、加长、加参考或升档。draft（starter / 快速 / 短 / 低分辨率）与 final（已批准提示+参考进高质量）分路由。
- 开渲前写死 retry ceiling：连续约 2–3 次失败后换模型、简化动作、拆镜或加强参考（次数为来源建议，待核）。盲抽不算迭代，因为没有可复用知识。

## 可执行

- 每镜日志记：尝试次数、credits、排队+渲+审+返工分钟、通过/拒因；用公式算通过单价，勿只记成片那一条。
- 先用最短时长与最低可用分辨率验证；构图/运动签字后再升档或加对白。
- draft 与 final 分队列：未批准的提示/参考不进高质量渲染。
- 开渲前写下本镜 ceiling（建议连续 2–3 次，待核）；达顶必须换模型 / 简化动作 / 拆镜 / 加强参考之一，禁止同设置盲抽。
