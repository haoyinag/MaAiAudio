# 通用技巧：万相 3.0 对台词与背景音乐使用显式空约束

- **主维度：** `general`（通用技巧）
- **来源 URL：** https://help.aliyun.com/zh/model-studio/wan3-video-generation-prompt-guide
- **发布机构 / 作者：** 阿里云百炼 Model Studio
- **发布日期：** 2026-10-16（页面更新时间）
- **采集日期：** 2026-11-16（Asia/Shanghai）
- **来源等级：** 模型厂商官方文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** 万相 3.0 视频生成；中国大陆 / 全球可用区以百炼控制台为准
- **时效：** 高；模型默认行为与提示词偏好可能随版本变化

## 来源明确事实

1. 官方指南说明，不写台词约束时模型会自行决定是否加入台词；若不需要台词，应显式写“无台词”或 `No dialogue.`。
2. BGM 有三种控制方式：不写时由模型自选，写明风格时由提示词指定，完全不需要时应显式写“无 BGM，只生成环境音和动作音”或 `No background music.`。
3. 指南允许未使用的提示板块直接跳过；负向清单只写确实不希望出现的内容，不要求凑满，也不应重复正向约束。

## 分析推断

- “留空”与“明确不要”不是同一种控制：留空把决定权交给模型，显式空约束才表达交付禁项。
- 这是万相 3.0 的当前官方行为说明，不能未经同素材测试就外推到所有视频模型。

## 可执行含义

1. 分镜验收表为 `台词`、`旁白`、`BGM` 分别设置“模型自选 / 明确指定 / 明确禁止”三态，不用空白单元格同时表达三种含义。
2. 需要后期独立配音或配乐的镜头，在生成提示中明确禁止对应音轨，避免生成后再做不稳定的分离。
3. 负向清单只保留交付禁项；画面、声音和运镜的正向要求仍放回对应字段。
