# AI 短视频 / 短剧知识库

持续收集 **AI 短视频**、**AI 短剧** 的制作与增长经验，形成可检索、可迭代、可溯源的内部知识库。

本目录是知识库的权威文档树。仓库 Wiki 首页应链到本路径（见 [WIKI.md](./WIKI.md)）。

## 怎么读

1. **做视频实操前先读（持续滚动）**：[当下全局最佳实践手册 PLAYBOOK.md](./PLAYBOOK.md)（整合所有已核验版本的端到端工作流、模型路由、困境边界与变现分账）
2. **看每日最新情报（可能尚未进入正式版）**：打开 [CURRENT.md](./CURRENT.md) 或直接读最新 [日摘要（2026-11-27）](./inbox/2026-11-27/DIGEST.md)
3. **看[本轮正式版本候选](./v2026.11.26/README.md)和最近已发布正式快照**：读 [已发布版摘要 v2026.11.20/CHANGELOG.md](./v2026.11.20/CHANGELOG.md) 及 [基线大版 v2026.09.13/CHANGELOG.md](./v2026.09.13/CHANGELOG.md)
4. **查原始证据与参数细节**：按链接下钻原子稿；inbox INDEX 与日目录仅溯源

## 版本节奏

- **每日巡扫**：先写六维 `SCAN.md` 账本（含正向技巧、工作流、行业困境与变现），再把通过分层核验的线索写成 inbox 原子稿与 `DIGEST.md`，先入库、后定稿。
- **约每 3 天发一版**：将已核验条目并入 `vN/`，同步滚动更新 [PLAYBOOK.md](./PLAYBOOK.md) 与 [CURRENT.md](./CURRENT.md)。
- 旧版本目录保留，便于对照与回滚阅读，不原地改写已发布条目的事实结论。

## 来源与写作约束

- **必须标注来源**：每条经验写明原始链接与观察/采集日期。
- **去重**：同一事实或同一案例不重复落条；重复线索在 inbox 中合并并保留更完整的出处。
- **不编造**：没有出处的数字、案例、平台规则不要写入正式条目；不确定的内容停在 inbox，并标明「待核验」。
- **不写入密钥或本机绝对路径**：正文只用仓库相对路径与公开链接。
