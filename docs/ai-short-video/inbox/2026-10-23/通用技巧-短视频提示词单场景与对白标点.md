# 通用技巧：短视频提示词按单场景拆分，对白用冒号避免误生文字

- **主维度：** `general`（通用技巧）
- **来源 URL：** https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/best-practice
- **发布机构 / 作者：** Google Cloud
- **发布日期：** 页面未注明
- **采集日期：** 2026-10-23（Asia/Shanghai）
- **来源等级：** 模型厂商官方文档
- **核验状态：** `已核验`
- **适用平台 / 地区：** 全球；Gemini Omni、Veo；方法可作为其他视频模型的待测模板
- **时效：** 当前产品文档，模型行为易变，核验至 2026-10-23

## 来源明确事实

1. Google 建议用清晰、直接、消除歧义的提示词，并把镜头角度、主体表情和光线等写成可观察描述。
2. 对短视频，一个提示词应聚焦一个场景；把“发现线索—驾车—对峙”等连续事件拆成独立片段，避免输出混乱或不完整。
3. 对白应在说话动作后用冒号引出且避免引号，以降低模型把对白渲染成画面文字的概率。
4. 官方把 9:16 列为 TikTok、Instagram Reels 与 YouTube Shorts 等移动优先平台的重要画幅。

## 分析推断

- 可把“一个提示词一个时空连续动作”设为默认拆镜门；对白标点是模型相关规避法，不应未经测试外推到所有模型。
- 镜头拆分后仍需人工检查角色、道具、声线和空间连续性。

## 可执行含义

1. 分镜表每行只保留一个地点、一个主要动作和一个情绪目标；跨地点或明显时间跳转另起镜头。
2. 用同一对白各跑一次“带引号 / 冒号无引号”小样，记录误生字幕率后再固定模板。
3. 竖屏成片在生成前锁定 9:16，不把横屏生成后的强裁切当默认方案。
