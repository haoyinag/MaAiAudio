# 制作管线：多镜头故事板保存五类逐镜字段

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://ir.kuaishou.com/zh-hans/news-releases/news-release-details/keling30xiliemoxingquanmianshangxian
- **发布机构 / 作者：** 快手科技
- **发布日期：** 2026-02-05
- **采集日期：** 2026-11-10（Asia/Shanghai）
- **来源等级：** 模型厂商官方公告
- **核验状态：** `单一来源`
- **适用平台 / 地区：** 可灵 3.0；结构可迁移到其他分镜工作流
- **时效：** 中高

## 来源明确事实

1. 可灵 3.0 Omni 的故事板可逐镜指定时长、景别、视角、叙事内容和运镜。
2. 产品同时支持参考视频、多图输入和视频内编辑。
3. 官方未提供字段组合的成功率或通用最佳值。

## 分析推断

- 上述字段适合作为模型无关的 shot manifest，便于生成、复审和返工时定位变化。

## 可执行含义

1. 每镜保存 `duration / shot_size / viewpoint / action / camera_motion`。
2. 身份与场景参考使用资产 ID 引用，不在每镜重复粘贴长描述。
3. 返工只修改失败字段，保留已通过字段和参考资产。

## 与既有条目的关系

- **增量：** 把既有分镜提示词进一步固化为可追踪的逐镜清单。
