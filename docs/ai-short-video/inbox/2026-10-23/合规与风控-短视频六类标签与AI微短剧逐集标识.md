# 合规与风控：短视频六类必选标签与 AI 微短剧逐集标识并行执行

- **主维度：** `compliance`（合规与风控）
- **来源 URL：**
  - https://www.cac.gov.cn/2026-05/12/c_1780328273108117.htm
  - https://www.nrta.gov.cn/art/2026/7/31/art_113_73785.html
- **发布机构 / 作者：** 中央网信办；国家广播电视总局
- **发布日期：** 2026-05-12；2026-07-31（办法自 2026-09-01 起施行）
- **采集日期：** 2026-10-23（Asia/Shanghai）
- **来源等级：** 监管部门官方
- **核验状态：** `交叉验证`
- **适用平台 / 地区：** 中国大陆短视频发布；境内播出的 AI 生成、制作微短剧
- **时效：** 极高；法规与平台落实方式易变，核验至 2026-10-23

## 来源明确事实

1. 中央网信办要求平台把内容标注设为短视频发布必经环节，发布者须在“含有虚构演绎内容”“含有AI生成内容”“含有营销信息”“内容为转载”“内容为个人观点”“无需标注”六类必选标签中选择一项。
2. 平台还应巡检新增内容，并分批回溯存量短视频；“无需标注”用于真实生活记录且不在页面呈现。
3. 《微短剧发展管理办法》自 2026-09-01 起施行，适用于境内通过网站、应用、分发平台及多类终端面向公众播出的、单集少于 20 分钟且情节连续完整的剧集。
4. 办法第三十四条要求使用 AI 技术生成、制作的微短剧由制作机构和播出单位依国家规定在每集明显位置添加提示标识；第二十七条另要求片头明显标注剧名及相应许可 / 批准 / 节目编号。

## 分析推断

- 平台发布页的六选一标签、成片内逐集 AI 提示和微短剧片头许可信息是不同层级的动作，不能互相替代。
- 同时含 AI、营销或虚构演绎时，六选一 UI 如何表达多重属性取决于平台具体实现；监管答问没有授权创作者自行忽略其他义务。

## 可执行含义

1. 国内发布清单拆成三栏：平台发布标签、每集画面 AI 提示、片头许可 / 批准 / 节目编号；逐项验收。
2. 在母版与平台版都保留标识图层和导出记录，避免二次裁切遮挡明显位置。
3. 多属性内容发布前核对目标平台当期 UI 与规则；无法确认时标为待核验，不凭经验代选。
