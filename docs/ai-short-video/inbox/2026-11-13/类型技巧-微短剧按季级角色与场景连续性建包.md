# 类型技巧：微短剧按季级角色与场景连续性建包

- **主维度：** `types`（类型技巧）
- **来源 URL：** https://runway.com/use-cases/microdramas
- **发布机构 / 作者：** Runway
- **发布日期：** 页面未标明
- **采集日期：** 2026-11-13（Asia/Shanghai）
- **来源等级：** 模型厂商官方用例页
- **核验状态：** `单一来源`
- **适用平台 / 地区：** Runway 微短剧工作流；拟发 TikTok、Reels、YouTube Shorts 或短剧应用的竖屏连载
- **时效：** 中高；为厂商当前产品方法，效果需项目内验证

## 来源明确事实

1. Runway 的微短剧用例页建议把主要角色固定为整季共用的参考，逐镜生成场景，并从上一镜的画面继续，以延续房间、光线和服装状态。
2. 页面把“重复出场的角色”“连续的场景”“集级包装”分开列出；包装包括标题卡、冷开场、悬念收尾与竖屏封面。
3. 官方用例将单集描述为 9:16、由短镜头拼接而成的约 60–90 秒片段；这是厂商给出的格式建议，不是所有平台的强制标准。
4. 页面宣称参考可保持跨集身份和场景，但没有公开失败率、样本量或跨模型对照。

## 分析推断

- 微短剧的最小制作单元不只是“一个镜头”，还应有一份跨集使用的季级状态包，把角色、场景、服装与包装承诺锁定。
- 连续上一帧只能延续局部视觉状态，不能替代剧情、道具和权利元数据。

## 可执行含义

1. 开季前锁定主演参考、场景参考、服装状态和命名规则，并记录每次变更影响的集数。
2. 每个镜头同时记录起始状态、结束状态和下一镜承接帧；转场时主动断开错误的画面继承。
3. 把标题卡、冷开场、集尾悬念和封面作为独立验收项；用实际发布数据验证，不从厂商页面推导留存或分发效果。

## 与既有条目的关系

- **增量：** 既有条目分别覆盖季集结构、角色资产和多镜头故事板；本条把它们合并为“季级状态包 + 逐镜承接帧 + 集级包装”的类型验收单元。
- **边界：** 不采信厂商对跨集一致性的效果宣称为独立事实。
