# Seedance 五层分镜：goal / sequence / shot / prompt / check

- 维度：制作管线
- 日期：2026-09-13

## 一句话

分镜不是「先写一句再开渲」，而是 goal → sequence → shot → prompt → check 五层；转场对写进分镜，开渲前把接受标准写死。

## 要点

- 五层各挡一类失败：goal 定视频要完成的事；sequence 定镜数（短片常用 3–6 镜）；shot 写 framing / 运镜 / 动作 / 光 / 转场；prompt 把单镜转成可渲指令；check 对照输出是否过线。
- prompt 模板含 Continuity + Constraints：连续镜重复同一产品/角色/场景锚，并写清禁止项（可读文字、变形手、漂移脸等）。
- 开渲前写死接受标准：产品可辨、服装不变、运镜平滑、末帧可接下一镜。本条盯「分镜卡上的 check 层」，不重开批量评审流程。
- 转场对写进分镜，不只靠剪辑：运动匹配、形状匹配、色匹配、动作匹配、景别匹配。
- 结构示例：Hook→problem→transformation→result；或 establishing→action→detail→hero。

## 可执行

- 开渲前先填五层卡：一句话 goal、3–6 镜 sequence、每镜 framing/运镜/动作/光/转场、带 Continuity+Constraints 的 prompt、可勾选 check。
- 每镜 check 至少勾：产品可辨、服装不变、运镜平滑、末帧可接下一镜；未写死不进生成。
- 相邻镜在分镜卡上写好转场对（运动/形状/色/动作/景别），禁止只在时间线上临时找切点。
- 广告/社媒优先 Hook→problem→transformation→result；旅行/地产/生活方式优先 establishing→action→detail→hero。
