# 制作管线：Seedance 含输入视频按最低用量算账

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://docs.volcengine.com/docs/ark/model-pricing?lang=zh
- **辅助来源 URL：** https://docs.volcengine.com/docs/ark/list-video-generation-tasks-api?lang=zh
- **发布机构 / 作者：** 火山引擎方舟文档中心
- **发布日期：** 页面未标明
- **采集日期：** 2026-11-18（Asia/Shanghai）
- **来源等级：** 模型厂商官方计费与 API 文档
- **核验状态：** `交叉验证`
- **适用平台 / 地区：** 火山方舟 Seedance 2.0 / 2.5 系列；中国大陆
- **时效：** 极高；单价、最低用量和模型范围可能变化

## 来源明确事实

1. Seedance 视频价格由 token 单价与 token 用量共同决定；高分辨率通常高于低分辨率，含输入视频与不含输入视频的计价档不同。
2. 含输入视频的 Seedance 2.0 / 2.5 任务若估算用量低于当前分辨率、比例和输出时长对应的最低 token 用量，按最低用量计费。
3. `usage.completion_tokens` 可作为计费对账依据；仅成功生成的视频计费，因审核等原因生成失败不收费。

## 分析推断

- 短输入视频不保证成本线性下降；落入最低用量区间时，继续缩短输入可能不再降低账单。
- 成本应以任务实际 `completion_tokens` 对账，而不是只用理论公式。

## 可执行含义

1. 提交前按模型、分辨率、比例、输出时长和是否含输入视频调用当前价格计算器。
2. 保存 `estimated_tokens / minimum_tokens / actual_completion_tokens / billed_amount`，批量任务先用少量样本校准。
3. 多个短参考片段可能分别触发最低用量；比较合并输入、降低调试分辨率或无视频参考的总成本，但不能只为降费牺牲一致性。

## 已知困境与边界

- 最低 token 表和单价易变，本文不固化具体价格；执行时必须回查官方页面。
- “审核失败不收费”不等于效果不满意可退款。

## 与既有条目的关系

- **增量：** 新增含输入视频任务的最低 token 地板与实际用量对账字段。
