# 单集形状：冷开场三型 + 中段一反转 + 悬念四型

- 维度：类型技巧
- 日期：2026-09-13

## 一句话

单集按 cold open（约 0–3s）→ 中段恰一个 reversal → 末镜 cliffhanger；钩子与悬念先静帧审批再烧视频 credits。

## 要点

- 相对上午「60–90s 完播连载」、09-11「每集一个转折 / 末约 10s 悬念」：本条只记开场三型、悬念四型与「解决前一拍」停法，不重开完播时长或胶片抛光。
- 来源把单集压成三截：冷开场占约 0–3s，中段只装一个 reversal，末镜挂悬崖（来源作者归纳，待核）。
- 开场三型：脸部反应 / 一句冲击台词 / 已在进行的揭示。禁止建立镜、片头卡、人物走进画面开场。
- 悬念四型：reveal（观众先看见角色没看见的）/ threat（危险进画但未落地）/ revelation（角色得知后停在反应）/ decision（二选一，切开在抉择前）。一律停在「解决前一拍」；付费墙可落此处。
- 钩子镜与悬念镜先做竖屏静帧分镜审批，再烧视频 credits；钩子镜建议约 3–4 候选且全取（来源建议，待核）。

## 可执行

- 每集剧本先填三格：0–3s 开场型（脸/台词/进行中揭示）、中点一个 reversal、末镜四型之一；缺格不进分镜。
- 开场禁止建立镜与片头卡；冲击台词只留一句、一镜，勿把对白塞进同一短生成。
- 末镜选四型之一，切在解决前一拍；本集最后几秒禁止把悬崖答完。
- 钩子与悬念先出竖屏静帧，导演签字后再进视频；钩子镜按约 3–4 候选全生成再挑（来源建议，待核）。
