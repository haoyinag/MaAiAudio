# 即梦首尾帧 vs 全能参考 + @素材名

- 维度：制作管线
- 日期：2026-09-13

## 一句话

单首帧图+prompt 走「首尾帧」；多模态走「全能参考」，并用 `@素材名` 指定每条素材的用途。

## 要点

- 仅首帧图 + prompt →「首尾帧」入口。
- 多模态（图 / 视频 / 音频 / 文本）→「全能参考」入口。智能多帧 / 主体参考不可选时以产品手册为准，不凭教程硬选。
- 用 `@素材名` 指定用途，例：`@图片1` 作首帧、`@视频1` 参考镜头语言、`@音频1` 配乐。不标注时模型会猜角色，参考可能被当成背景。
- 社区教程称全能参考常见上限约 9 图 + 3 视频 + 3 音频、素材时长约 ≤15s（以产品实际 UI 为准，待核）。
- 本条只记入口分流与 `@` 用途，不重开 09-12 即梦权重 / 2–4s 组合。

## 可执行

- 只有一张首帧图+文案：进「首尾帧」，不要为了「高级」强行全能参考。
- 有视频/音频或超过一张图：进「全能参考」；每条素材在提示词里用 `@素材名` 写清用途。
- 智能多帧或主体参考入口看不到时，停手对照手册，不按第三方教程猜按钮。
- 社区上限（约 9 图 + 3 视频 + 3 音频、时长约 ≤15s）只作预算，实际上线前以当前 UI 为准。
