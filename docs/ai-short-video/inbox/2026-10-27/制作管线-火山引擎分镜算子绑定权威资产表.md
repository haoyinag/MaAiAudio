- **时效：** 当前在线算子清单，核验至 2026-10-27

## 来源明确事实

1. “分镜脚本生成”在线算子可把输入文本转换为标准 `storyboard_bundle`，支持剧本结合人物、道具、场景三类资产 JSON 生成分镜，也支持口播文案直接生成分镜。
2. 剧本模式会保留输入资产的标识与设定，把镜头绑定到对应人物、道具和场景。
3. 口播模式按语义组织镜头时长、画面动作、口播和可供后续视频生成使用的结构化描述。
4. 配套视频分镜算子可输出场景汇总、人物注册表、场景切片、人物出现区间、关键帧与代表图片，并返回 token 用量和 LLM 请求次数。

## 分析推断

- 资产 ID 比自由文本名称更适合作为脚本、分镜、生成和返修之间的稳定连接键。
- 算子输出是生产草稿，不是成片质量证明；人物聚合、镜头边界和资产绑定仍需人工验收。

## 可执行含义

1. 先冻结人物、道具、场景三张权威资产表及唯一 ID，再生成分镜。
2. 分镜验收至少检查 `镜头时长 / 资产绑定 / 动作 / 口播 / 生成描述` 五列。
3. 将 token 用量、请求次数和返修次数一并写入成本台账，区分生成成本与人工修订成本。
