# 制作管线：Firefly 代理执行前先审计计划与跨项目约束

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://news.adobe.com/news/downloads/pdfs/2026/11/firefly-release-max-2026.pdf
- **发布机构 / 作者：** Adobe
- **发布日期：** 2026-11-10
- **采集日期：** 2026-11-11（Asia/Shanghai）
- **来源等级：** 工具厂商官方发布稿
- **核验状态：** `单一来源`
- **适用平台 / 地区：** Adobe Firefly Creative Agent / Firefly Video；全球，以账户开放为准
- **时效：** 极高；多项新能力处于 beta 或 preview

## 来源明确事实

1. Adobe 于 2026-11-10 公布 Firefly Creative Agent 的新能力，包括一次设定格式、色彩、品牌指南、角色和产品偏好，并跨项目应用。
2. Plan Mode 允许创作者在代理开始前审查、编辑和批准计划；Model Selector 允许手动选模型或使用自动选择。
3. Firefly Video 宣布把叙事弧、场景、镜头、简化时间线、字幕、转场和 B-roll 串联在一个流程；Firefly Graph beta 支持构建可重复工作流。
4. Always-on agents 仅为 preview；发布稿没有提供自动质检准确率、失败恢复或处理时延基准。

## 分析推断

- 代理工作流的可控点应放在“计划批准”和“持久约束”，而不只是最终成片复核。
- 跨项目偏好能减少重复输入，但也会把错误约束放大到多个项目，因此需要版本和变更记录。

## 可执行含义

1. 代理开始前导出计划摘要，人工确认镜头清单、模型选择、资产来源与费用上限。
2. 品牌、角色和产品约束按版本保存，变更时记录影响的项目。
3. beta / preview 能力仅进入小批量试运行；保留人工质检、中止、回滚和外部归档路径。

## 与既有条目的关系

- **增量：** 补充 2026-10-22 Firefly 项目资产/时间线闭环之后的跨项目偏好、计划审批与可重复 Graph 流程。
- **关联：** 与 Runway Agent“先审计划再消耗生成积分”相同的控制原则可合并实施，但两者产品能力不互相替代。
