- **采集日期：** 2026-10-28（Asia/Shanghai）
- **来源等级：** 服务厂商官方文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** AIGC 短剧、漫剧和电商视频生产；服务可用区域以产品控制台为准
- **时效：** 当前产品文档与接口能力，核验至 2026-10-28

## 来源明确事实

1. 官方质量评估工具可按参考信息一致性、世界合理性、内容持续性和视觉保真度检查生成视频，并返回异常时间区间、问题说明与典型问题帧。
2. 参考一致性模块要求提供 1–6 张参考图，并按人物、服饰、商品、场景、道具或其他类别标注。
3. 世界合理性覆盖重力、碰撞、流体、支撑平衡、惯性、光影、尺度透视、人体交互等问题；视觉保真度覆盖人体、物体和中英文字结构。
4. 官方给出的闭环是：合格视频进入编辑，疑似问题转人工复核，严重问题触发重新生成。

## 分析推断

- 质检输出最有价值的不是单一总分，而是“模块 + 时间区间 + 问题帧”，因为它能直接决定局部修复、人工复核或整镜重生。
- 厂商文档只证明检查接口和字段存在，不证明检测准确率、误报率或节省工时；上线前仍需用项目样本校准阈值。

## 可执行含义

1. 在镜头资产表为每张参考图增加类别，并把人物、服饰、商品、场景、道具分开挂接。
2. 把质检结果落成 `shot_id / module / start / end / evidence_frame / action`，动作限定为通过、人工复核、局部修复、重生。
3. 先用已人工标注的通过 / 失败镜建立小样本，比较误报和漏报后再决定自动分流阈值。
