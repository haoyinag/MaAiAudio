# 制作管线：视频生成端点停用前先做模型迁移与回归验收

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://ai.google.dev/gemini-api/docs/video
- **发布机构 / 作者：** Google AI for Developers
- **发布日期：** 页面未标明；页面当前停用提示核验于 2026-11-03
- **采集日期：** 2026-11-03（Asia/Shanghai）
- **来源等级：** 模型厂商官方开发文档
- **核验状态：** `已核验`
- **适用平台 / 地区：** 使用 Gemini API / Veo 预览端点的视频生成管线；全球
- **时效：** 极高；模型 ID、预览状态与停用日期会变化

## 来源明确事实

1. Google 当前视频生成文档警告，Gemini API 中的 `veo-3.1-generate-preview`、`veo-3.1-fast-generate-preview` 和 `veo-3.1-lite-generate-preview` 已于 2026-10-22 停用。
2. 文档要求迁移到 Gemini Omni Flash（`gemini-omni-1.1-flash`）或 Gemini Enterprise Agent Platform 中可用的一般可用模型，以避免服务中断。
3. 页面将 Gemini Omni Flash 描述为支持视频生成和对话式视频编辑的当前接口，但没有承诺旧端点与新模型输出完全一致。

## 分析推断

- 模型 ID 不是静态配置；把预览端点硬编码进批处理会形成单点停机风险。
- 迁移验收不能只看请求成功，还要比较时长、画幅、音频、参考素材遵循、内容过滤和单位成本等行为差异。

## 可执行含义

1. 建立模型注册表，至少记录供应商、模型 ID、生命周期状态、替代模型、最后核验日期和回退策略。
2. 为同一组黄金 brief 同时跑旧基线样本与新模型，检查镜头字段、音频、参考一致性、错误码和耗时后再切流。
3. 对预览模型设置到期提醒和功能开关；批量任务在模型不可用时应停止并报警，不要静默换模后继续交付。

## 与既有条目的关系

- **增量：** 既有制作管线条目主要讨论模型分工与镜头验收；本条新增“端点生命周期 + 迁移回归”这一生产运维门。
- **不替代：** 不证明 Gemini Omni Flash 在质量上优于 Veo 3.1 Preview；只记录官方停用与迁移要求。
