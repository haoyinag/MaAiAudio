# 多角色声线卡：一句一意图；15s 内对话宜短；按角色分轨

- 维度：制作管线
- 日期：2026-09-14

## 一句话

先建多角色声线卡（年龄感/音色/语速等），台词一句一意图；15s 内对话要短，30s+ 拆多回合并按角色分轨生成。

## 要点

- 相对上午「台词先于视频 + 悬崖成对剪」：那边管出轨顺序与 5s+5s 接缝；本条管声线卡字段与多角色分轨，不重开成对剪。
- 声线卡字段：年龄感、音色、语速、音量、情绪上限、停顿习惯、口头禅、禁区（如勿播音腔）。
- 台词一句一意图；15s 内对话要短；30s+ 拆成多回合，用反应镜 / 沉默拼接。
- 按角色**分轨**生成，不要一条混轨里叠多个声线设定。
- 口型失败先诊断：台词太长 / 站位不清 / 说话人标错——勿无限抽卡。
- 把声音问题写回剧本 / 分镜，而不是只在生成器里改参数。

## 可执行

- 开渲前每角色一张声线卡：八项填满（年龄感、音色、语速、音量、情绪上限、停顿、口头禅、禁区）；缺卡不进对白镜。
- 对白表加「意图」列：一句只办一件事；15s 窗内的来回先压短，30s+ 段落拆回合并插入反应镜或沉默。
- 生成按角色分轨，合成时再叠；禁止在同一条生成里同时指定两套声线。
- 口型失败按清单查：句长、站位、说话人标签；三项都过仍失败再换模型，禁止盲抽。
- 审片听到串味 / 播音腔 / 抢拍，把问题写回剧本或分镜，下一轮从稿面改。
