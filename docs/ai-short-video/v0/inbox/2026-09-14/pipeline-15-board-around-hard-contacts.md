# 硬接触易崩：接吻/打斗绕开，穿门拆两镜，手机屏后期叠字

- 维度：制作管线
- 日期：2026-09-14

## 一句话

接吻、打斗、两体接触易崩——分镜绕开（接近→切→余波）；穿门换景拆成两镜；手机/文字屏先生成空白再后期叠字。

## 要点

- 相对 09-11「写剧本规避模型短板 / 渲前四门」与 09-13「primary job」：本条只记三类硬接触的分镜绕法，不重开规避清单或选型门槛。
- 来源点名仍会破的点：接吻、打斗、以及任何两具身体接触的戏。分镜绕开：接近 → 切开 → 余波，不要赌单镜内完成接触（ScreenWeaver，待核）。
- 角色穿过一扇门进入另一场景：拆成两镜，永不做「一门一镜换景」。
- 手机屏、短信、文件、路牌等文字：先生成空白屏幕/空白纸面，后期叠字。竖剧大量用电话插入镜，模型渲字仍不稳定。
- 长对白口型仍弱：句子写短，切到听者，再切回（与 09-13「口型差改侧面/远景」互补，本条只记剪接点，不重开口型兜底）。

## 可执行

- 分镜评审加「硬接触」列：接吻 / 打斗 / 拥抱 / 握手标红，默认改写成接近→切→余波三拍。
- 穿门、进出电梯、车门换景一律拆成「门外/门内」两镜，禁止单次生成跨场景。
- 凡出现可读文字的道具（手机、电脑、合同、路牌），提示词写 blank screen / blank paper，字在剪辑叠。
- 对白超过一句：切听者反应，再切回；不要把整段独白塞进同一生成。
