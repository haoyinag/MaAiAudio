# 权利当元数据 + 国内作者归纳四条生死线

- 维度：合规与风控
- 日期：2026-09-12

## 要点

- 权利当元数据：声线 / 音乐 / 肖像 / 参考图附来源、许可、同意、是否可商用。
- 国内作者归纳四条生死线（第三方教程，**非官方法条**）：①网文改编须授权（文称截取比常被平台卡，勿私改）②禁可识别真人脸 / 明星声 ③素材 / 配乐 / 字体须可商用 ④片头 / 平台要求标注「AI生成」。
- 商用前读清工具 ToS；AI 生成 ≠ 免责。
- MCPlato 亦强调发行前合规 / 备案与音乐版权风险（文提及 RIAA 诉 Suno/Udio；商用 BGM 需审权利）。诉讼与备案要求均为来源作者转述，待核。

## 可执行

- 每条声线、音乐、肖像、参考图入库时写上来源、许可、同意、是否可商用，缺一项不进商用成片。
- 国内发行按作者归纳四线自检（第三方教程，非官方法条）：改编先授权且勿私改截取比；不用可识别真人脸/明星声；素材配乐字体须可商用；片头按平台要求标「AI生成」。
- 商用前读生成工具 ToS；把「AI 生成」当成仍须授权的生产手段，不是免责声明。
- 发行前过备案与 BGM 权利审查；Suno/Udio 类生成音乐不默认可商用（作者转述待核）。
