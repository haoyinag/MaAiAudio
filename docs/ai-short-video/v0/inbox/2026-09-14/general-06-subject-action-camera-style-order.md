# 提示词顺序：Subject → Action → Camera → Style（→ Constraints）

- 维度：通用技巧
- 日期：2026-09-14

## 一句话

提示词按 Subject→Action→Camera→Style（必要时再加 Constraints）写；靠前信息权重更高；每镜一个动作 + 一个运镜，可加物理细节。

## 要点

- 相对 09-13「八层提示词 / 行为型提示词 / 物理向提示词」：本条只记注意力顺序与「一动作一运镜」，不重开八层字段表或 Seedance vs Kling 词库。
- 来源把 Seedance 2.0 公式写成：主体 → 动作 → 镜头 → 风格 → 限制。模型对靠前信息权重更高；风格写在最前、主体写在后，容易氛围对、主角糊（YouMind 归纳，待核）。
- 每镜一个动作（现在时、单一动词）+ 一个运镜。同时写「推轨+左摇+环绕」易晃、不自然。
- 可加物理细节触发模拟：风吹头发、落水飞溅、布料随动作垂坠。限制宜用肯定句（keep face consistency）多于堆否定。
- 交叉来源称提示词约 120–280 词较稳（作者博客，待核）；本条不把它写成硬规。

## 可执行

- 每镜提示词先写四段再生成：谁（外貌/服装）→ 正在做什么 → 唯一运镜 → 一个风格锚；失败时只改其中一段。
- 运镜词只留一个（push-in / pan / tracking / handheld / orbit 等）；需要第二种运动就拆下一镜。
- 动作句用现在时，并补一条物理细节；不要用「他会走过去然后……」这种将来时清单。
- 约束写成「单一主体、比例稳定、重力一致」，少写一长串 no extra fingers。
