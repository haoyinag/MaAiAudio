# 制作管线：Seedance 样片确认后在有效期内转正式视频

- **主维度：** `pipeline`（制作管线）
- **来源 URL：** https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh
- **发布机构 / 作者：** 火山引擎方舟文档中心
- **发布日期：** 页面未标明
- **采集日期：** 2026-11-16（Asia/Shanghai）
- **来源等级：** 模型厂商官方 API 文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** 火山方舟 Seedance 2.5 样片模式；中国大陆
- **时效：** 极高；任务有效期、可复用参数和模型范围均可能变化

## 来源明确事实

1. Seedance 2.5 样片模式分两步：先生成 Draft 视频，再用返回的样片任务 ID 生成正式视频。
2. 正式生成会自动复用部分样片参数，另有部分参数禁止重复传入或允许重新指定；具体规则须以样片模式文档为准。
3. 2026-10-28 10:00（UTC+8）及以后创建的 Draft 任务 ID 有效期为 14 天；更早的 ID 有效期仍为 7 天，超期后不能再转正式视频。

## 分析推断

- Draft 更适合作为进入高成本正式生成前的审批门，而不是长期素材归档格式。
- 只保存预览文件而不保存任务 ID、创建时间和复用参数，会让“样片已批准”仍无法稳定转为正式视频。

## 可执行含义

1. 样片账本至少记录 `draft_task_id / created_at / expires_at / prompt 版本 / 参考素材版本 / 审批人 / 审批结论`。
2. 把正式生成排在样片有效期内，并设置提前到期提醒；未通过的样片不进入正式生成队列。
3. 转正式前按官方参数复用规则生成请求，不把 Draft 阶段全部参数机械重传。
