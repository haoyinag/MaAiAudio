# 通用技巧：即梦数字人口播按动作与镜头状态写提示词

- **发布机构 / 作者：** 火山引擎即梦 AI
- **发布日期：** 页面最近更新时间 2026-01-19
- **采集日期：** 2026-10-28（Asia/Shanghai）
- **来源等级：** 模型厂商官方文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** 即梦 OmniHuman 1.5 数字人口播；中国
- **时效：** 当前产品文档，模型行为易变，核验至 2026-10-28

## 来源明确事实

1. 官方建议用连贯自然语言、具体动作和少否定表达，避免孤立词堆砌；图中已有的静态服饰等特征不必重复描述。
2. 推荐结构为“镜头运动 + 角色情绪 + 说话状态 + 具体动作 + 可选背景事件 / 其他角色动作”。
3. 文档提示 15 秒以内结构稳定性较好；人脸过小可能出现口型不动，人物长时间离镜后再入镜可能发生一致性变化。
4. 运镜可通过描述镜头结束状态来约束速度和结束位置；极端姿势、角度和复杂场景存在失败概率。

## 分析推断

- 数字人口播提示词应优先描述“接下来发生的动作”，而不是重复输入图的静态信息；镜头终态可以转化为可验收字段。
- “15 秒以内较好”是该产品的厂商经验，不应外推为其他模型的统一时长上限或稳定性承诺。

## 可执行含义

1. 把单镜脚本拆为 `运镜 / 情绪 / 说话状态 / 动作 / 背景动作 / 镜头终态` 六列。
2. 口型关键镜避免超远景；需要角色离镜再入镜时，拆镜并重新挂接角色参考。
3. 对超过 15 秒、极端角度或多人复杂动作先做短样片，验收后再扩展时长。
