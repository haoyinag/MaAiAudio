# 通用技巧：结构仿拍先按素材职责选输入

- **主维度：** `general`（通用技巧）
- **来源 URL：** https://docs.volcengine.com/docs/creative-agent/structural-imitation-guidelines?lang=zh
- **发布机构 / 作者：** 火山引擎 Kickart 文档中心
- **发布日期：** 页面最近更新于 2026-08-28
- **采集日期：** 2026-11-13（Asia/Shanghai）
- **来源等级：** 模型 / 工具厂商官方文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** Kickart 结构仿拍；中国大陆；其他参考驱动型视频工具需小样本试验
- **时效：** 高；产品输入要求与效果可随版本变化

## 来源明确事实

1. 官方指南将人物、商品和场景素材分开处理：人物建议清晰正脸、干净背景与单人画面；商品建议白底或干净背景、多角度且同组只放一个 SKU；场景建议完整、无人遮挡且与原片视角和光线接近。
2. 对指定真人，文档建议在半身 / 全身图外单独提供人脸特写，以降低 ID 漂移。
3. 商品输入可在白底图、实拍图与参考视频之间按目标选择；文档称其内部对照中参考视频在商品一致性和综合分上略有优势，但没有公开样本量或评测方法。
4. 官方不建议把带大量花字、营销特效和参数说明的图片作为主输入，因为可能导致文字崩坏、双重字幕或图案错乱。

## 分析推断

- 参考包应按“身份、形体 / 比例、表面细节、场景空间”分工，不宜让一张终稿营销图同时承担所有控制目标。
- “参考视频更好”只是厂商文档中的特定对照结果，不能扩大为跨模型结论。

## 可执行含义

1. 建立参考素材表，为每张图 / 每段视频标注主体、职责、角度、SKU 和权利来源。
2. 人物、商品、场景分别准备最小参考包；密集小字、营销特效和无关人物先清理。
3. 同一镜头用白底图与参考视频做小样本对照，分别验收身份、比例、细节、文字和运动。
