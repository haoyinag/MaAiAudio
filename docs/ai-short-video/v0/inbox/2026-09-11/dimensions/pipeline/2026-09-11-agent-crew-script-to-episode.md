# 多智能体剧组：制片/分集分镜/DOP 分模路由

标签: 多智能体,分镜,管线

## 要点
- 全剧剧本 + bible 先装进 creative producer（系列单一真相源），再每集一个 storyboard agent（各自 notebook）
- DOP agent 按镜路由：Veo 对话/表演；Kling 原生多镜衔接；Seedance 2.0 reference-to-video 对齐已有帧/上一镜
- 序列先广建立，后续镜用 Seedance 引用上一视频作空间布局
- 时长不够优先 extend，勿重生；每镜生成 3–4 备选；插入镜可跳过场景表直出
- 厂商案例宣称：3 人团队 3 天交付 10 集（约 1.5–2 分钟/集），约 $1000/集（厂商自报，待核）
