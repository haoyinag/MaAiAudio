# 制作管线：即梦 API 把成功计费、并发与资源包溢出设成三道门

- **主维度：** `pipeline`
- **来源 URL：** https://docs.volcengine.com/docs/jimeng-ai/jimeng-ai-video-generation-billing-instructions?lang=zh
- **发布机构 / 作者：** 火山引擎即梦 AI
- **发布日期：** 页面未标明
- **采集日期：** 2026-11-25（Asia/Shanghai）
- **来源等级：** 模型厂商官方计费文档
- **核验状态：** `单一来源`
- **适用平台 / 地区：** 火山引擎即梦视频生成 API；中国大陆
- **时效：** 高；价格、并发与资源包规则易变

## 来源明确事实

1. 文档说明只对成功生成的视频计费，并按模型、分辨率和成功输出时长计价。
2. 付费调用的默认并发通常为 2，部分模式为 1；因此提交量不能直接当作同时处理能力。
3. 资源包用尽后不会自动停止调用，而会转为按量计费；资源包有效期一年且购买后不支持退款。

## 分析推断

“失败不计费”不能替代预算保护：真正的成本黑洞可能来自大量技术成功但业务不可用的成片，以及资源包耗尽后无感切换到按量账单。

## 可执行含义

1. 队列器同时检查 `并发槽位 / 资源包余额 / 按量预算开关`，任一越界即暂停新任务。
2. 成本表分 `调用失败 / 技术成功但业务拒收 / 最终采用` 三态；只用厂商账单无法计算废片成本。
3. 批量前用一小组代表镜头测平均处理时间与业务可用率，再按并发 1–2 反推交付排期。

## 已知困境与边界

- 当前价格数字易变，本条不固化跨项目单价；执行前应重新打开官方计费页。
- “成功生成”是计费状态，不是内容质量、合规或可交付保证。
- 与既有预扣/返还账本互补；本条新增资源包耗尽自动转按量和低并发吞吐边界。
