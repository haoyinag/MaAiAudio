# 制作管线：Seedance 资源包同时设到期与超额门禁

- **主维度：** `pipeline`
- **来源：** [Seedance 模型资源包规则](https://docs.volcengine.com/docs/ark/seedance-2-0-model-resource-pack-rules?lang=zh)
- **发布机构：** 火山引擎
- **页面更新时间：** 2026-11-16
- **采集日期：** 2026-11-19（Asia/Shanghai）
- **来源等级：** 模型厂商官方计费文档
- **核验状态：** 已核验

## 来源明确事实

资源包购买后立即生效，有效期 90 天，到期未用 Token 自动作废；不同模型版本的资源包不能互相抵扣。扣费顺序为对应模型资源包、专属节省计划、账户余额，额度用尽或到期后会自动转按量付费。新购 7 天内且未使用可申请退款，已使用或超过 7 天不支持退订。

## 分析推断

资源包的单位价不能单独代表项目成本；闲置到期和自动转后付费分别形成浪费与超支风险。

## 可执行含义

1. 采购前按 90 天内可确认的正式镜头量测算，不用乐观产能填满资源包。
2. 账本增加模型版本、包到期日、剩余额度、预计耗尽日和后付费金额。
3. 在 70 / 85 / 95% 用量以及到期前 30 / 14 / 7 天告警；版本切换先确认对应资源包。

## 已知困境与边界

- 价格和活动可调整，应以结算页为准；本文不固化折扣后的单价。
- 资源包只抵扣在线推理，不等于覆盖人工、版权、返工和发布成本。
- 与昨日最低 token 计费条目互补：昨日讲单次任务地板，本条讲采购周期、版本错配和自动超额。
