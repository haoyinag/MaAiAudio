# 按镜分模矩阵与三路生镜

- 维度：制作管线
- 日期：2026-09-12

## 要点

- 按镜路由：Seedance≈叙事/多镜/参考锚定；Kling≈动作/运动控制；PixVerse C1≈分镜面板连续；Wan≈量大便宜预览。
- 三路生镜：identity 关键用 R2V；有明确起止用 first-last-frame；动作用 motion control。
- 好片太短用 extend；坏片才 regenerate。对白二遍：先画面后口型/avatar，短句+字幕兜底。

## 可执行

- 分镜表加一列「模型路由」，按叙事/动作/面板连续/预览四类落模，勿一镜一模型乱试。
- 角色锚定走 R2V，起止明确走首尾帧，动作戏走 motion control。
- 成片偏短先 extend；只有崩坏才重生。对白先锁画面，再补口型/avatar，短句加字幕。
