# 竖屏对白落中三分之一，底约 1/4 让给字幕与 UI

- 维度：平台技巧
- 日期：2026-09-13

## 一句话

竖屏把对白放在画面中三分之一；底部约 1/4 留给字幕和平台 UI；发布前用手机审每一集前约 3 秒。

## 要点

- 相对 09-11「竖屏默认动态逐词字幕」、09-10「竖屏分镜」：本条只记安全区与发布前手机审前 3 秒，不重开字幕样式或 9:16 导出规格。
- 对白（说话的嘴、关键反应脸）放画面中三分之一，避开上下被裁、被贴纸挡住的带（来源教程，待核）。
- 底部约 1/4 预留给字幕与平台界面，不要把关键动作或脸压进底边（来源教程，待核）。
- 系列被判断的是「每一集」的前约 3 秒，不是只审第一集片头；发布前用手机看完每集开头（来源作者口径，待核）。

## 可执行

- 分镜/静帧先画中三分之一安全框与底约 1/4 UI 带；对白脸和手势不准落入底带。
- 字幕叠在底带内，不挡中三分之一的嘴与眼神。
- 导出后用手机审每一集前约 3 秒：安全区、字幕、平台 UI 是否互挡；未过不发。
- 禁止把横屏宽构图裁成 9:16 再补救安全区。
